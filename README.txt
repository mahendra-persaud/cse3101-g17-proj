School Management System

This is our final group project submission for the database course. We built a School Management System using PHP and MySQL. We tried to follow the MVC pattern as discussed in class.

Group Members:
- Group 17

Installation Instructions:
1. Please use XAMPP (we used the latest version).
2. Copy the project folder into your "htdocs" directory.
3. Start Apache and MySQL in the XAMPP Control Panel.
4. Go to PHPMyAdmin and create a new database called "School_Management".
5. Import the "database.sql" file that is in the project folder.
6. Open your browser to: http://localhost/cse3101-g17-proj/
